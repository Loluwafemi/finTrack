To run this app successfully.
First:
    Activate the virtual environment by executing this on your terminal:
    ```
    venv/Scripts/activate
    ```


Lastly:
    Run the application with this command:
    ```
    fastapi dev app/main.py
    ```


Root app: fastapi

Dependencies:
    pytesseract [v 0.3.13]: A file manager library to generate a structured data from receipt files such as [image and pdf].
    sqlmodel [v 0.0.24]: An ORM library to manage and handle transaction from users to the database.
